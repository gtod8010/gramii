# 그래미서비스 프로젝트 개요

## 🎯 프로젝트 소개
그래미서비스는 소셜미디어 마케팅 서비스 플랫폼으로, 인스타그램/유튜브/틱톡 등의 팔로워, 좋아요, 조회수 등을 제공하는 B2C 서비스입니다.

## 🏗️ 기술 스택

### Frontend & Backend
- **Next.js 15.2.3** (App Router)
- **React 19** 
- **TypeScript**
- **Tailwind CSS v4** (UI 프레임워크)

### 데이터베이스
- **PostgreSQL** (운영 DB)
- **Pool 커넥션** 방식 사용

### 외부 연동
- **RealSite API** (메인 서비스 제공자)
- **2PM API** (보조 서비스 제공자) 
- **InstaMonster API** (인스타그램 특화 서비스)

## 🚀 멀티 사이트 지원

### 브랜드별 분리 운영
- **gramii** (그래미): 포트 3000
- **orda** (오르다): 포트 3001

### 환경 분리
- 브랜드별 독립적인 데이터베이스
- 환경변수를 통한 설정 분리
- 빌드/배포 프로세스 분리

## 📋 핵심 기능

### 사용자 관리
- 회원가입/로그인 (JWT 기반)
- 포인트 시스템
- 추천인 코드 시스템

### 서비스 관리
- 3단계 카테고리 구조 (카테고리 > 서비스 타입 > 서비스)
- 외부 API 연동을 통한 실시간 서비스 동기화
- 사용자별 맞춤 가격 설정

### 주문 시스템
- 실시간 주문 처리
- 외부 벤더 API 연동
- 주문 상태 추적

### 관리자 기능
- 서비스 관리
- 사용자 관리
- 포인트 관리
- 정산 관리

## 🔄 데이터 흐름

1. **서비스 동기화**: 외부 API → realsite_services 테이블
2. **서비스 등록**: realsite_services → services (관리자가 수동 등록)
3. **주문 처리**: 사용자 주문 → 외부 API 호출 → 주문 상태 업데이트

## 📱 모바일 앱 연동
- **Android SMS Forwarder** (인증 SMS 자동 처리)
- **ORDA SMS Forwarder** (오르다 브랜드용)

## 🎨 UI/UX
- TailAdmin 템플릿 기반
- 반응형 디자인
- 다크모드 지원
- 현대적이고 직관적인 인터페이스
